> Scaffolder for Zobi

## Installation

First, install [Yeoman](http://yeoman.io) and `generator-zobi` using
[npm](https://www.npmjs.com/) (we assume you have pre-installed [node.js](https://nodejs.org/)).

```bash
npm install -g yo
npm install -g @zobi-ui/generator-zobi
```

## Usage

Generate a new package or visualization plugin:

```bash
mkdir /tmp/zobi-plugin-chart-hello-world
cd /tmp/zobi-plugin-chart-hello-world
yo @zobi-ui/zobi
```
